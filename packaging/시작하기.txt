FlightQA {version} — UAV 다중분광 비행 데이터 품질 진단
빌드 {build_date} · git {git_hash}

■ 실행
  FlightQA.exe 를 더블클릭합니다. 설치가 필요 없고 인터넷 연결도 필요 없습니다.
  (빌드한 PC 에서는 바탕화면·시작 메뉴의 FlightQA 바로가기로도 실행됩니다.)
  Windows 가 "알 수 없는 게시자" 경고를 내면 [추가 정보] → [실행] 을 누르세요.

■ 사용 순서
  1. 홈 화면에 원본 데이터 폴더(MicaSense SET 폴더 또는 DJI 미션 폴더)를 끌어다 놓습니다.
  2. 분석이 끝나면 결과 화면에서 판정과 권고 행동을 봅니다.
  3. [보고서 열기] 로 HTML 보고서, [데이터 내보내기](Ctrl+E) 로 CSV·GeoJSON·GeoPackage·GeoTIFF 를 저장합니다.
     GeoPackage(flightqa.gpkg) 와 tif 는 QGIS 에 끌어다 놓으면 바로 열립니다.

■ 조정기 임무 파일(KMZ)
  Pilot 2 에서 내보낸 임무 KMZ 를 데이터 폴더에 함께 두면 실제 임무 폴리곤으로 조사 구역을 판정합니다.
  없으면 촬영 궤적에서 구역을 추정합니다.

■ 명령줄
  tools\flightqa-cli.cmd run <폴더>            분석 + 보고서
  tools\flightqa-cli.cmd run <폴더> --mission 임무.kmz
  tools\flightqa-cli.cmd --help

■ 문서
  docs\README.md        전체 설명서
  docs\QA_RULES.md      판정 규칙과 임계값 근거
  docs\ASSUMPTIONS.md   확정 사실과 가정

■ 참고
  이 폴더의 숨김 항목(_internal 등)은 프로그램 구성 요소입니다. 옮기거나 지우지 마세요.
  폴더 전체를 통째로 복사해야 다른 PC 에서 실행됩니다.
